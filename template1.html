Type Coercion (The Trap)

JS tries to "guess" types. This is dangerous. Always use strict equality ===.

// Loose Equality (Bad)
"5" == 5; // true (Wait, what?)

// Strict Equality (Good)
"5" === 5; // false (Different types)
Always use === unless you have a very good reason not to.

Truthy vs Falsy

Every value in JS can be treated as true or false in an if statement.

Falsy Values (Counts as false)
  • false
  • 0 (Zero)
  • "" (Empty string)
  • null
  • undefined
  • NaN (Not a Number)
Truthy Values (Counts as true)

Everything else!

  • "Hello"
  • 42, -1
  • [], {} (Arrays/Objects)
