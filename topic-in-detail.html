# Topic in Detail ## 1. Connecting Multiple Pages A website becomes useful when visitors can move easily from one page to another. Instead of creating separate websites, developers connect pages using hyperlinks. Example: ```html Home Destinations Gallery ``` When users click these links, the browser opens another HTML file in the same project. --- ## 2. Consistent Navigation Professional websites keep the same navigation bar on every page. For example: ```text Home | Destinations | Gallery ``` Benefits: * Users always know where to go. * The website feels organized. * Navigation is easier. The only change is highlighting the active page. Example: * Home page → Home highlighted * Destinations page → Destinations highlighted * Gallery page → Gallery highlighted --- ## 3. Building the Destinations Page The **Destinations** page provides more detailed information about travel locations. Each destination should have: * Image * Destination name * Short description * "Learn More" button Example layout: ```text Tokyo (Image) Experience Japan's modern cities and rich culture. [Learn More] ``` Students should use a responsive grid to display multiple destination cards. --- ## 4. Building the Gallery Page The Gallery page focuses on visuals instead of text. Students will display beautiful travel images using a responsive grid. Each gallery image should: * Have rounded corners * Include shadows * Scale slightly when hovered * Maintain equal spacing Example: ```text 📷 📷 📷 📷 📷 📷 ``` --- ## 5. Keeping a Consistent Design Every page should use the same: * Colors * Fonts * Navigation bar * Footer * Button styles * Card design * Spacing Consistency makes a website look professional. --- ## 6. Testing Navigation Before publishing a website, developers test every navigation link. Students should verify that: * Home opens correctly. * Destinations opens correctly. * Gallery opens correctly. * Every page links back to the others. Broken links create a poor user experience. ---
